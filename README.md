# Northstar — Standard Homepage Starter

A beginner-friendly, responsive business homepage built with plain HTML, CSS, and JavaScript. It is intended as a teaching/demo project for developing a homepage with Qoder.

## What's included

- `index.html` — semantic homepage sections and content
- `css/style.css` — layout, colors, typography, responsive styles
- `js/script.js` — mobile navigation and dynamic copyright year
- `images/` — place your own image assets here

## Run the project

1. Extract the ZIP file.
2. Open the `standard-homepage-starter` folder in Qoder.
3. Open `index.html` in a browser.

You can use the Qoder preview/live preview feature if available in your setup. Otherwise, open `index.html` directly in your browser.

## Homepage sections

1. Header and navigation
2. Hero section
3. Trust/approach strip
4. About section
5. Services section
6. Why choose us
7. Call to action
8. Footer

## Suggested teaching sequence

1. Open `index.html` and identify the semantic elements: `header`, `nav`, `main`, `section`, and `footer`.
2. Ask Qoder to explain the structure before changing anything.
3. Change the logo, company name, headings, and paragraph copy.
4. Open `css/style.css` and adjust the CSS variables in `:root` to change the theme.
5. Replace the CSS illustration and about placeholder with real images.
6. Ask Qoder to explain the mobile navigation code in `js/script.js`.
7. Resize the browser to test the responsive breakpoints.

## Useful Qoder prompts

**Understand the project**
> Explain how this homepage is structured. Walk me through each section in index.html and show which CSS rules style it. Do not modify any files.

**Customize the design**
> Update the homepage to match this brand direction: [describe colors, typography, and visual style]. Keep the existing section structure and make sure the design remains responsive.

**Add a section**
> Add a testimonials section between Services and Why Choose Us. Match the existing design system, use semantic HTML, and make it responsive.

**Debug**
> Review the homepage for HTML, CSS, accessibility, and responsive layout issues. Explain each issue and suggest a fix before changing the code.

## Notes

This is a front-end starter only. It does not include a CMS, backend, contact form processing, analytics, or deployment configuration. The contact button currently opens an email link; replace the example email address before publishing.
